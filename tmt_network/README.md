# TMT产业链网络 v0.45

A股半导体+TMT全产业链交互式网络图（D3.js 力导向图）。从上游矿产到下游终端全链路可追溯，既是投研工具，也是可探索的星图叙事。

**当前快照：** 226 节点（A股 185 / 海外 31 / 非上市 10）· 454 边（L1 202 / L2 252）· 68 行业分组

## 交付文件

| 文件 | 用途 |
|---|---|
| `tmt_network_full.html` | 单文件应用：力导向图 + 飞船系统 + 舰长日志（浏览器直接打开） |
| `tmt_network_data.js` | 数据文件：NODES / EDGES / NODE_DESC，可直接编辑扩展 |
| `README.md` | 本文件 |

**注：** 舰长日志的全部文案池（到达事件/评级评价/商船故事/放松句/随笔等）内嵌于 `tmt_network_full.html` 的模板池中，无需外部文档。

**注意：** HTML 修改后需 Ctrl+F5 强刷（浏览器缓存会造成"改动无效"假象）。

## 一、分析框架（方法论核心）

### 1. 核心逻辑

- 偏好**"海外垄断 + 供给硬约束"**与**"供应链武器化受益"**的结构性壁垒叙事
- 从底层技术原理理解标的，对逻辑纯度要求严格：无实质强化的概念保持冷静
- 每条供应链边上必须有一端是 A 股节点，图服务于 A 股投资决策

### 2. 四层采集策略

| 层级 | 来源 | 置信度 | 适用场景 |
|---|---|---|---|
| T1 | IPO招股书（近5年科创板） | 0.90+ | 中小市值锚点公司，客户/供应商全名披露 |
| T2 | 年报MD&A经营评述 | 0.85+ | 大市值龙头公司的"管理层讨论与分析" |
| T3 | 年报前五大表格 | 金额校验 | 大市值>1000亿几乎100%打码，仅参考 |
| T4 | 行业新闻/互动易/研报 | 0.50-0.80 | 前五大覆盖不到的边，交叉验证 |

### 3. 三轮关键修正（历史教训）

1. **大市值打码→锚点策略**：转向中小市值（200-800亿）近5年IPO公司
2. **前五大表格→MD&A优先**：打码≠没有金标，MD&A文字段落更诚实
3. **光模块链L2→新材料链**：光模块前五大被海外芯片主导，转攻半导体材料→晶圆厂链

### 4. 评级体系

| 级别 | 定义 | 视觉 |
|---|---|---|
| S（国内） | 供应链不可替代的物理瓶颈 | 金色大光晕 |
| S（外部瓶颈） | 全球市占>70% + 无替代供应商 + 下游需求刚性 | 金色大光晕 |
| A | 行业龙头或核心瓶颈 | 橙色中光晕 |
| B | 重要但非瓶颈 | 无光晕 |
| C | 边缘节点 | 无光晕 |

## 二、数据结构（字段规则）

### 节点 NODES

```javascript
{id:"中际旭创", code:"300308", group:"光模块", type:"a", rating:"S", py:"zjxc", products:["800G光模块","1.6T光模块"]}
```

| 字段 | 说明 |
|---|---|
| `id` | 节点名称（唯一，渲染时统一加"星"字） |
| `code` | A股股票代码（海外/非上市节点可缺省） |
| `group` | 行业分组（决定行业着色） |
| `type` | `a`=沪深 / `o`=海外 / `n`=非上市 |
| `rating` | S/A/B/C 四级重要性，可缺省（无评级节点不参与评级评价） |
| `py` | 拼音首字母（搜索用） |
| `products` | 产品列表（舰长日志产品占位符数据源） |

### 边 EDGES

```javascript
{source:"源杰科技", target:"中际旭创", type:"L1", method:"L1_equity", confidence:0.99, sourceDoc:"..."}
```

| 字段 | 说明 |
|---|---|
| `source` / `target` | 节点 id；方向 = 供应关系（source 供 target） |
| `type` | L1=金标实线 / L2=银标虚线 |
| `method` | L1_direct / L1_equity / L2_news / L2_bidirectional 等 |
| `confidence` | 0-1 置信度 |
| `sourceDoc` | 数据来源说明（**无裸边，必填**） |

### 节点简介 NODE_DESC

```javascript
{ id: "细分赛道 + 核心能力 + 关键客户/方向" }
```
S+A 级节点必填，作为 tooltip 简介。

### 链归属（HTML 内两表）

- `CHAIN_GROUP`：group → 链映射（行业级归属）
- `CHAIN_EXTRA`：公司 → 链映射（个股级补充归属，新节点需同步追加）

## 三、填写准则（入库规范）

### 新增节点工作流

1. `tmt_network_data.js` 的 NODES[] 追加节点（id/code/group/type/rating/py/products）
2. EDGES[] 追加边，填写 type/method/confidence/sourceDoc
3. S+A 级追加 NODE_DESC 条目
4. 检查 `CHAIN_EXTRA` 是否需要补充链归属
5. 刷新 HTML 验证渲染

### 规范一：desc-边对齐

- desc 含"供X"/"X供应商" → 对应边至少 L1，confidence ≥ 0.80
- desc 含"间接"/"经X→"/"通过X供" → 对应边 L2，confidence ≤ 0.79
- desc 含"进入X供应链"（未明确直供） → 可为 L2
- 改 desc 必须同步检查边；改边必须同步检查 desc

### 规范二：外部节点边规则

| 组合 | 处理 |
|---|---|
| o→o（海外互供） | **不保留**，删边；连带无 A 股连接则移节点 |
| o→n / n→o / n→n | 保留（国内非上市品牌对理解供应链有价值） |
| 一端为 `a` 的任意组合 | 全部保留 |

**核心原则：图上每条边至少一端是 A 股节点。**

### 规范三：置信度标准

| 级别 | 置信度 | 证据要求 |
|---|---|---|
| L1 | 0.80-0.99 | 年报/招股书 MD&A 直接点名；互动易官方回复；重大合同公告 |
| L2 | 0.50-0.79 | 多份独立研报交叉验证；行业报道无官方确认；供应链信息推演 |
| L3 | <0.50 | 单一传闻；纯逻辑推导（不建议入库） |

关键判据：**信息是否来自供应商自身官方披露且明确提及客户名称。** 年报点名 → 自动 L1，无例外。

### 规范四：链归属验证

入库新节点时验证已有产业链归属，追加到 HTML 的 CHAIN_EXTRA 映射表。

## 四、HTML 功能实现

### 图交互

| 功能 | 规则 |
|---|---|
| 点击星球 | 聚焦（供应链上下游高亮）+ 飞船飞抵 + 日志 |
| 再次点击同一星球 | 切换上下游方向（up ↔ down） |
| 点击空白 | 退出聚焦，恢复全量显示 |
| 聚焦层级 | 滑块 1-5（5=∞），localStorage 持久化 |
| 着色切换 | 🎨 类型 → 行业 → 产业链 三态循环 |
| 图例点击 | 按链/组筛选 |
| 搜索 | 名称/代码/行业/拼音，Enter 跳转定位 |
| 拖动节点 | 力导向重排（松手后恢复 alpha） |

**性能规则（聚焦/筛选/搜索状态）：** 不相关**连线**用 `display:none` 真正隐藏（不参与每帧绘制）；**节点/标签**降半透明保留可见（opacity 0.1/0.05）。这是避免 SVG 单图层重绘卡顿的关键。

### 飞船系统

| 行为 | 规则 |
|---|---|
| 首次飞行 | 页面加载 3 秒后自动飞向随机 A 股星球（折叠日志） |
| 点击飞行 | 飞抵点击星球，折叠日志 |
| idle 巡航 | 默认 90s 首次 / 30s 间隔（滑块可调），随机选星**排除当前星球**，完整日志 |
| 巡航 UI | idle 期间隐藏除日志外所有 UI（标题/搜索/面板/图例/统计），0.3s 淡入淡出；用户交互（点击星球/点空白/搜索/拖动/缩放）即退出巡航恢复 UI |
| 航迹 | 40 圆点，出生点位于船尾偏移处；火焰渐变：最新红 → 橙 → 白黄 → 最老蓝；jitter ±0.8 |
| 绕行 | 角速度 0.02，进入轨道 |

### 舰长日志

**结构：** `📖 舰长日志 + T历时间` → 到达事件 → 评级评价 → 商船故事 → 客户句(50%) → 供应商句(30%) → 放松句(50%) → 随笔

**T历时间编码：** 年两位 + 月字母(A-L) + 日 + 时字母(A-X) + 分（如 `T历26H0324年I38日`）

**模板池：**

| 池 | 数量 | 说明 |
|---|---|---|
| `arrivalTemplates` | 50 | 到达事件 |
| `ratingComments` | S/A/B/C 各 30 | 评级评价 |
| `merchantStories` | 100（全含 `{p}`） | 商船故事主体，`lv` 字段分池 |
| `relaxDetails` | 50 | 放松句（太空错位日常、日记体、时间/地点锚点） |
| `captainClosings` | 200 | 随笔收尾 |
| `customerAddons` / `supplierAddonsSP/S/P` | 3 / 各 4 | 客户句 / 供应商句模板 |

**商船故事 lv 分池规则：** 无 `lv` = 通用；`lv:"SAB"` 仅 S/A/B；`lv:"SA"` 仅 S/A；`lv:"BC"` 仅 B/C。筛选表达式 `s.lv.indexOf(rating) !== -1`。

**占位符：**

| 占位符 | 替换 | 强调色 |
|---|---|---|
| `{p}` | 产品（取自节点 products） | 金 `#f0c040` |
| `{c}` | 客户（取自下游邻居） | 蓝 `#58a6ff` |
| `{s}` | 供应商（取自上游邻居） | 紫 `#a371f7` |
| `{r}` | 放松句位置（50% 概率出现） | 淡金斜体 |

**供应故事三池（30% 触发）：** SP池（供应方+其产品）/ S池（纯供应方）/ P池（纯产品，产品从指向当前星球的链的上游合集取）。转折语（至于/说到/提及/论起）+ 本港/本地商会/进口交易中心情境主体。无下游时"全宇宙都需要这些宝贝"。

**配色规则：** 链名/供应商紫、行业金、等级（S金/A橙/B蓝/C灰）、星球名白粗 14px、产品金、客户蓝、放松句淡金斜体。所有"xxx星"的"星"字不变色不加粗。仅级别/公司名/股票代码加粗。

**折叠态：** 仅显示三个句号点 `···`（纯文本），点击展开；折叠时不显示标题/正文/✕。
